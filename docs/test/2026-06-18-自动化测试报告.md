## 四、测试覆盖的功能清单

### 4.1 上下文感知（对标 RAG-Anything ContextExtractor）

- [x] `ContextConfig` 配置类（6 参数：context_window / context_mode / max_context_tokens / include_headers / include_captions / filter_content_types）
- [x] `ContextExtractor` page 模式（按 page_idx 窗口提取 MinerU 全文上下文）
- [x] `ContextExtractor` chunk 模式（按 index 窗口提取相邻 chunk）
- [x] `ContextExtractor` text_chunks 模式（从字符串列表提取上下文）
- [x] 自动格式检测（auto 模式根据输入类型自动选择提取策略）
- [x] 截断逻辑（在句末/换行/段落边界截断，无断点时加省略号）
- [x] `get_context_extractor()` 工厂函数（从 settings 读取默认值，允许覆盖）
- [x] `StructuredContent.raw_content_list` 挂载（MinerU 原始列表传递给 ContextExtractor）
- [x] `StructuredContent.list_index` 全局序号（供 chunk 模式定位）
- [x] `StructuredContent.section_path` 从 text_level 推导章节路径
- [x] 图片/表格标题字段规范化（image_caption / img_caption / table_caption 兼容）
- [x] 多模态 VLM prompt 注入文档上下文
- [x] 多模态 LLM 表格分析 prompt 注入文档上下文
- [x] 多模态 LLM 公式解释 prompt 注入文档上下文
- [x] `_get_context_for_content()` 优先级（raw_content_list > neighbor_text > 空）

### 4.2 异步并发处理（对标 RAG-Anything asyncio.Semaphore + gather）

- [x] `_parse_with_mineru` 使用 `asyncio.to_thread` 包装同步解析
- [x] `_process_multimodal_chunks` 阶段1并发 VLM/LLM 描述生成
- [x] `_process_multimodal_chunks` 阶段2串行组装 DocumentChunk
- [x] `_build_knowledge_graph` 并发实体提取
- [x] 并发数受 `settings.multimodal_max_parallel` 控制
- [x] 并发数受 `settings.kg_entity_max_parallel` 控制
- [x] 单条失败容错（不影响其他内容处理）
- [x] `batch_upload_documents` 并发导入受 `batch_max_concurrent` 控制

### 4.3 配置参数（settings.py 新增）

- [x] 上下文感知 6 参数默认值 + 环境变量覆盖
- [x] 并发控制 2 参数默认值 + 环境变量覆盖

## 六、备注

- 所有测试均可在**无外部依赖**（无 MySQL / Qdrant / Neo4j / LLM API / MinerU）环境下运行
- 外部依赖均通过 `unittest.mock` 的 `patch` / `AsyncMock` / `MagicMock` 进行 mock
- `magic_pdf` 模块通过动态注册 `types.ModuleType` mock 到 `sys.modules` 实现测试
- asyncio 协程测试使用 `@pytest.mark.asyncio` 装饰器
